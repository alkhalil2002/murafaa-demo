# مُرافعة (Murafaa)

منصة إدارة مكاتب محاماة مدعومة بالذكاء الاصطناعي للسوق السعودي — عربية، RTL، مبنية على أنظمة وإجراءات التقاضي السعودية.

> **هذا المستودع حزمة تسليم للبناء.** الكود الحقيقي يُبنى من الصفر وفق الوثائق. النموذج الحالي مرجع بصري فقط.

## ابدأ من هنا

1. **`CLAUDE.md`** — ملف التحكّم لكلود كود. يُقرأ أولاً وفي كل جلسة. يحوي الـ stack والقواعد الإلزامية وترتيب البناء.
2. **`docs/`** — الوثائق المرجعية:
   | الملف | المحتوى |
   |---|---|
   | `01-business-analysis.md` | تحليل العمل (الرؤية والمنتج) |
   | `02-technical-spec.md` | المخطّط التقني الكامل (المعمارية، الـ stack، خطة البناء) |
   | `03-data-model.md` | الكيانات والحقول والعلاقات |
   | `04-permissions-matrix.md` | الأدوار والوحدات وطبقات الفرض |
   | `05-screens-inventory.md` | كل الشاشات والمكوّنات والأيقونات |
   | `06-business-rules.md` | القواعد الدقيقة (الاعتراض، VAT، الأتعاب…) |
3. **`prototype/murafaa-prototype.html`** — النموذج عالي الإتقان (مرجع UX، بيانات وهمية).

## أول خطوة مع كلود كود

**لا تكتب كوداً في الجلسة الأولى.** اطلب من كلود كود قراءة `CLAUDE.md` وكل `docs/` والنموذج، ثم يكتب فهمه للمعمارية ونموذج البيانات وأسئلته المفتوحة. راجِع فهمه وأكّده، ثم ابدأ البناء وفق خطة `docs/02` (§13).

## الثوابت غير القابلة للتفاوض (ملخّص)

- الذكاء القانوني لا يُخرِج شيئاً دون **بوابة تحقق الاستشهاد** (قاعدة معرفية مغلقة).
- الصلاحيات تُفرَض **على الخادم** (3 طبقات)، لا في الواجهة.
- البيانات داخل المملكة (**PDPL**)، مع سجل تدقيق.
- قواعد العمل تُطبَّق حرفياً وتُغطّى باختبارات.

## الـ Stack

Next.js + TypeScript · Tailwind + shadcn/ui (RTL) · PostgreSQL + pgvector · Prisma · Claude عبر Vertex AI · Auth.js (OTP) · Google Cloud (الدمام). التفاصيل في `docs/02` و`CLAUDE.md`.
