# مُرافعة — قواعد العمل (Business Rules)

> **المصدر:** مستخرَج آلياً من دوال `prototype/murafaa-prototype.html`. كل قاعدة مذكورة مع دالتها والمنطق الفعلي.
> **الغرض:** ضمان أن الـ backend يُعيد تطبيق نفس القواعد بدقّة دون انحراف.

## ⚠️ قاعدة غير موجودة في النموذج — يجب إضافتها

النموذج **لا يحتوي** على بوابة التحقق من الاستشهاد القانوني (RAG + citation verification). أي مخرَج قانوني من الذكاء في النسخة الحقيقية **يجب أن يمرّ عبر قاعدة معرفية مغلقة + تحقق برمجي لكل مادة/سابقة** قبل عرضه. هذا أخطر متطلب قانوني، ومكانه الوثيقة التقنية. ساحة المرافعة والمساعد الحاليان يترافعان **دون اختلاق أرقام** كضابط مؤقت فقط.

## 1. مهلة الاعتراض على الحكم
**الدالة:** `_plus30(date)`
**القاعدة:** مهلة الاعتراض = **تاريخ الحكم + 30 يوماً** تقويمياً.
```
objectionDue = judgmentDate + 30 days
```
تُحسب تلقائياً عند تسجيل نطق الحكم، وتُولّد مهمة تذكير عاجلة. إن غاب التاريخ تُحتسب 30 يوماً من اليوم (`dateInDays(30)`).

## 2. ضريبة القيمة المضافة (VAT)
**النسبة:** **15%** على الصافي.
```
vat   = round(net × 0.15)
total = net + vat
```
تُطبَّق على: الفواتير، المصروفات، تسجيل الوقت، واحتساب الأتعاب. الفاتورة **شاملة الضريبة** في الإجمالي.

## 3. أنواع اتفاقيات الأتعاب (4)
**الدالة:** `caseFeeNet(case)` — تُرجع الصافي حسب نوع `fee.type`:

| النوع | المنطق |
|---|---|
| **مقطوع (flat)** | قيمة ثابتة `fee.value` |
| **شهري (retainer)** | اشتراك دوري ثابت |
| **بالساعة (hourly)** | مجموع (الساعات القابلة للفوترة وغير المفوترة من `TIME_ENTRIES` × `rate`) |
| **نسبة من المحكوم به** | `awarded × value / 100` (نسبة من المبلغ المحكوم به) |

الفاتورة تُولَّد من الاتفاقية عبر `mkInvoiceFromFee`.

## 4. كشف تعارض المصالح
**الدالة:** `caseConflicts(case)` — تفحص الخصم (`party`) والموكّل (`entity`) وتُرجع تنبيهات بدرجتَي خطورة:

| الحالة | الخطورة |
|---|---|
| الخصم مُسجَّل **عميلاً حالياً** للمكتب (في `CLIENTS`) | **high** — تمثيل ضد عميل |
| الخصم **عميل محتمل** في خط الأنابيب (`LEADS`) | **med** |
| الخصم هو **موكّلنا في قضية أخرى** | **high** |
| موكّلنا هو **خصم في قضية أخرى** | **high** |

تظهر النتيجة كشريط تحذير (`renderConflictBanner`) وشارة على بطاقة القضية.

## 5. مكافأة نهاية الخدمة
**الدالة:** `hrEos()` — حسب نظام العمل السعودي:
```
الأجر = الأساسي + البدلات (basic + allow)
إن كانت سنوات الخدمة ≤ 5:  المكافأة = 0.5 × الأجر × السنوات
إن كانت > 5:              المكافأة = (0.5 × الأجر × 5) + (الأجر × (السنوات − 5))
```
سنوات الخدمة = السنة الحالية − سنة الالتحاق (`joinY`).

## 6. السعودة (نطاقات)
**الدوال:** `nitaqatBand(pct)` · `saudistsNeeded(saudi,total,T)` · `isSaudi(name)`
- **النطاقات (`NITAQAT_BANDS`)** حسب نسبة التوطين: بلاتيني ≥90% · أخضر مرتفع ≥80% · أخضر متوسط ≥60% · أخضر منخفض ≥40% · أصفر ≥20% · أحمر ≥0%.
- **السعوديون المطلوبون** لبلوغ نسبة مستهدفة `T`:
```
needed = ceil( (T/100 × total − saudi) / (1 − T/100) )   ولا يقل عن 0
```
- الجنسية من `EMP_EXTRA[name].nat` (افتراضياً «سعودي»).

## 7. حالة الفاتورة
**الدالة:** `invStatusOf(invoice)` — تُشتق (لا تُخزَّن):
```
إن badDebt           → "دين معدوم"
إن المتبقّي ≤ 0       → "مدفوعة"
إن المدفوع > 0        → "مدفوعة جزئياً"
إن st = "متأخرة"      → "متأخرة"
غير ذلك              → "مستحقة"
```
المتبقّي عبر `invRemaining`، المدفوع عبر `invPaid`.

## 8. خصم السُّلف
**الدوال:** `advMonthlyOf(a)` · `advRemaining(a)`
```
القسط الشهري = a.monthly  أو  round(a.amount / max(1, a.months))
المتبقّي     = max(0, a.amount − a.paid)
```
يُخصَم تلقائياً ضمن مسيّر الرواتب الشهري.

## 9. إلحاح المهل
**الدالة:** `daysLeft(date) = ceil((date − today) / يوم)` — تُستخدم لتلوين المهل وترتيب التنبيهات (حرج/قريب/عادي).

## 10. تعدادات إجرائية ثابتة

| التعداد | القيم |
|---|---|
| **مراحل التقاضي** (`PROC_STAGES`) | الصلح → الدرجة الأولى → الاستئناف → النقض → التنفيذ |
| **أنواع الجلسات** (`HEARING_KINDS`) | تمهيدية، مرافعة، تبادل مذكرات، ضبط/إجراءات، سماع شهود، خبرة، حجز للحكم، نطق بالحكم، صلح، أخرى |
| **حالات التنفيذ** (`EXEC_STATUS`) | مطلوب، قيد التنفيذ، منفّذ، متعثّر |
| **مآلات القضية** (`outcome`) | كسب، جزئي، تسوية، خسارة (تُغذّي معدّل الكسب في اللوحة) |

## 11. أتمتة ما بعد الجلسة
- إنشاء مهام تحضير تلقائية للجلسة القادمة (`autoFromHearing`).
- كشف تعارض التقويم عند تداخل جلسات لنفس المحامي (`hearingClash`).
- تذكير العميل بالجلسة عبر واتساب (`remindClientHearing`).

## ملاحظة للـ backend
كل قاعدة محسوبة أعلاه (VAT، حالة الفاتورة، مهلة الاعتراض، نهاية الخدمة، السعودة، خصم السُّلف) **تُطبَّق في طبقة الخدمة**، لا في الواجهة، وتُغطّى باختبارات وحدة. التعدادات تُخزَّن كجداول مرجعية قابلة للتوسعة.
